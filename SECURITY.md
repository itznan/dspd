## Reporting a Vulnerability

If you discover a potential security issue in **dspd**, please do **not** open a public issue.

Instead, please report security vulnerabilities privately by:
- Creating a [GitHub Security Advisory](https://github.com/itznan/dspd/security/advisories/new), or
- Contacting the author via email or GitHub profile: [@itznan](https://github.com/itznan).

Please include:
- A description of the vulnerability.
- Steps to reproduce or a minimal proof of concept.
- Affected OS version and hardware environment.

We take security seriously and will investigate and respond promptly.
